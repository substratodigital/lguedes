# Regras do projeto Guedes.AI

- **NUNCA numerar nada** (cards, itens, listas, seções, serviços, etc.) sem pedido explícito do usuário.
- Ícones: usar sempre a biblioteca **Lucide** (line/stroke, uma cor, `stroke-width` 1.5–2), igual à versão original. Nunca trocar por emojis, caracteres ou outra biblioteca.
- Não inventar layouts novos para seções existentes: preservar a estrutura da versão original (v1 em `artifacts/guedes-ai`) e só mudar o que for pedido.
- Nunca usar barras de rolagem horizontais visíveis; quando o conteúdo exceder a largura, usar carrossel (GSAP) ou navegação por botões.
- Site somente em light mode.
