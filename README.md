# Guedes.AI - V2

Site institucional e plataforma de conteúdo do **Prof. Dr. Luís Guedes**.

## Estrutura do Repositório

- **`v2/site/`**: Aplicação Astro pura (HTML5, Vanilla CSS, GSAP, WebGL ASCII Shader, 100% Light Mode).
- **`v2/cms/`**: Sanity Studio com esquemas tipados para o professor gerenciar Artigos, Congressos, Livros, Prêmios e Mídia.
- **`v2/docs/`**: Documentação técnica e planejamento de fases.

## Tecnologias

- **Framework**: Astro (Zero runtime client-side desnecessário, SSG estático)
- **Animações**: GSAP 3 + ScrollTrigger
- **Design System**: Vanilla CSS com tokens HSL, tipografia Geist e dot-grid
- **Ícones**: Lucide Icons (inline SVG)
- **CMS**: Sanity.io (Google OAuth com 2FA)
- **Infraestrutura**: Cloudflare Pages + DNS Anycast
